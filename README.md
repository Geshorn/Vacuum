# Vacuum Rush

Робот-пылесос на гоночной трассе в 3D (Three.js), вид сверху под наклоном, камера едет за роботом.

## Запуск

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Затем открыть http://localhost:8080. Нужен интернет: Three.js грузится с CDN.

Управление: стрелки или WASD — руль и газ; на скорости в резком повороте робота немного сносит. Без нажатий через 6 с включается автопилот.
Пит-лейн — ответвление слева на стартовой прямой: ограничитель скорости, зарядная станция с зелёной площадкой. Автопилот заезжает туда сам при низком заряде.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html`, `css/style.css` | разметка и HUD: меню-бар, мини-карта, спидометр |
| `src/config.js` | все настройки и контрольные точки трассы |
| `src/track.js` | трасса: дорога, бордюры, стены, старт, зарядка, поиск позиции на трассе |
| `src/models.js` | 3D-модель робота-пылесоса (цвет и размер — из паспорта) |
| `src/menu.js` | меню выбора робота: портреты, 3D-превью, характеристики |
| `src/robots.js` | паспорта всех типов роботов: масса, скорость, мощность, ХП |
| `src/robot.js` | модель робота и физика: инерция, занос, дрифт, отскок от стен, автопилот |
| `src/world.js` | рендерер, свет, пол, камера |
| `src/hud.js` | интерфейс и реплики |
| `src/main.js` | игровой цикл: круги, батарея |
| `legacy/` | прошлая 2D-версия «пылесос на рабочем столе» |
